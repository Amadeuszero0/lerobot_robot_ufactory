# PiPER-X 关节流抖动分析与修复说明

## 问题定位

历史 Stage 1 每个控制周期都执行以下流程：

1. 读取存在通信和机械响应延迟的真实关节反馈；
2. 从该反馈位姿向 Pika 目标推进一个笛卡尔小步；
3. 以反馈关节角为种子重新求解 IK；
4. 将六个关节分别裁剪后直接发送 `JointCtrl`。

这会形成“机械臂尚未追上，软件又从滞后反馈重新规划”的追赶闭环。独立关节位置裁剪只能限制
位移，不能保证速度和加速度连续；数值 IK 在手腕多解或条件较差时还可能产生相邻周期解跳变。
因此，静态 FK 校验即使达到亚毫米精度，也不能保证动态关节流稳定。

## 修复内容

只有配置 `stabilized_stream: true` 时才启用修复逻辑，原 `01/02` 仍保留历史行为。

### 连续命令参考

修复版以上一次实际发送的关节命令作为：

- 下一周期的预测运动起点；
- 下一次 IK 的种子；
- IK 解连续性判断的参考。

真实关节反馈只用于跟随误差保护，不再直接作为每周期目标推进的起点。

### 关节动态限制

新增三层约束：

- 最大关节速度；
- 最大关节加速度；
- 最大单周期关节位置变化。

接近目标时禁止跨过目标，避免在目标两侧来回修正。

### 保护门

- `max_joint_following_error_deg`：真实反馈落后上一命令过多时保持目标，等待机械臂追上；
- `max_ik_solution_jump_deg`：IK 解相对上一命令跳变过大时拒绝推进；
- `ik_residual_limit`：IK 残差过大时保持上一命令。

### IK 连续性

IK 目标函数增加贴近上一命令种子的正则项 `ik_seed_weight`。修复配置同时提高阻尼并降低姿态
权重，减少 142.5 mm TCP 在手腕附近放大的激进修正。

## 修复版首轮参数

```text
控制频率                 50 Hz
最大关节速度             3 deg/s
最大关节加速度           20 deg/s²
最大单周期关节步长       0.10 deg
最大关节跟随误差         0.75 deg
最大 IK 解跳变           1.0 deg
笛卡尔步长               0.5 mm
旋转步长                 0.003 rad
Piper 速度               8%
Pika 平移比例             0.05
Pika 旋转比例             0.10
夹爪                     首轮关闭
退出行为                 只断开通信，保持关节使能和当前姿态
```

## 已完成的离线验证

- 26 个 Python 文件全部通过 AST 语法解析；
- 加速度限制首两周期关节步长分别为 0.008°、0.016°；
- 5° IK 分支跳变能够被保护门拒绝；
- 模拟反馈落后时能够保持上一命令；
- dry-run 可在无实机跟随的情况下推进模拟命令；
- 使用两台实机刚读取的关节姿态测试 0.5 mm/0.003 rad 六轴微扰：
  - IK 残差为 `0.000082～0.000209`；
  - 最大关节解变化为 `0.0923～0.2178°`；
  - 均低于残差阈值 `0.01` 和解跳变阈值 `1.0°`。

离线验证不能替代实机动态验证。实机必须依次执行 03 只读、04 左臂、05 右臂、06 双臂，
不得跳级。
