# piper 项目常用命令速查

整理时间：2026-08-06。覆盖环境、CAN、运行、监测、标定、排查、数据与 Git 同步。

## 1. 环境与安装

```bash
conda activate uf_lerobot
cd ~/lerobot_robot_ufactory

# 代码改动后重装一次（editable 安装一般会自动生效，重装更保险）
python -m pip install -e . --no-deps
python -m pip install -e ./piper --no-deps
```

## 2. CAN 配置（每次开机/重启后必做）

```bash
sudo ip link set can0 down
sudo ip link set can0 type can bitrate 1000000 restart-ms 100
sudo ip link set can0 txqueuelen 1000
sudo ip link set can0 up

# 验证状态与收发计数
ip -details -statistics link show can0
# 验证能收到机械臂持续反馈帧（2A1~2A8）
timeout 3 candump can0
```

## 3. 运行（当前终稿）

```bash
# 遥操（MOVE P direct，推荐）
uf-piper-teleop \
  --config_path=piper/config/single_pika_piper_movep_direct_final.yaml

# 录制测试（带 D435i RGB）
uf-piper-record \
  --config_path=piper/config/single_pika_piper_movep_direct_record.yaml
```

录制交互（headless，SSH 下）：

- Enter 开始；录满一个 episode 时长后 Enter 保存并进入下一个；Ctrl+C 退出。
- 有图形界面时：Space 开始、← 重录、→ 保存、Esc 退出。

## 4. 实时监测（关节 / 末端位姿）

快速一条命令（只读，不控制机械臂）：

```bash
python - <<'PY'
import time
from piper_sdk import C_PiperInterface_V2
p = C_PiperInterface_V2("can0", False)
p.ConnectPort(piper_init=False)
time.sleep(1)
try:
    while True:
        e = p.GetArmEndPoseMsgs().end_pose
        j = p.GetArmJointMsgs().joint_state
        print(f"X={e.X_axis/1000:7.1f} Y={e.Y_axis/1000:7.1f} Z={e.Z_axis/1000:7.1f} mm  "
              f"J1={j.joint_1/1000:6.1f} J2={j.joint_2/1000:6.1f} J3={j.joint_3/1000:6.1f} "
              f"J4={j.joint_4/1000:6.1f} J5={j.joint_5/1000:6.1f} J6={j.joint_6/1000:6.1f}",
              flush=True)
        time.sleep(0.2)
finally:
    p.DisconnectPort()
PY
```

或者用仓库里的工具（同样只读）：

```bash
python piper/tools/monitor_piper.py --port can0
```

安全参考位姿：`X=150~250, |Y|<100, Z=250~350, |J5|=20~35`。

```bash

python piper/tools/verify_ik_fk.py --port can0 --calibrate
```

## 6. 排查：进程 / 串口 / 相机

```bash
# 确认没有别的控制器在跑（尤其官方 piper_ros，会和录制抢 can0）
ps aux | grep -E "piper_ctrl|roslaunch|roscore" | grep -v grep

# 查 / 杀残留进程
ps aux | grep -E "uf-piper|python" | grep -v grep
pkill -f "uf-piper-teleop"
pkill -f "uf-piper-record"
pkill -f "piper_ctrl_single_node"

# Pika 串口占用检查（无输出 = 干净）
fuser -v /dev/ttyUSB50
lsof /dev/ttyUSB50

# 相机节点
ls -l /dev/v4l/by-id/ | grep -E "435i|405"
lerobot-find-cameras opencv
```

## 9. 最容易踩的三个坑

1. **重启后没配 CAN** → 各种 `Message NOT sent`，先跑第 2 节。
2. **官方 piper_ros 还在跑** → 两套控制器抢 can0，危险，先 `pkill -f piper_ctrl_single_node`。
3. **数据集目录已存在** → 录制入口会自动把空残留目录改名备份，但如果想续采用 `-r`。
